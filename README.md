# Kateryna Hnida — 3D-визуализация интерьеров

Лендинг-сайт 3D-визуализатора интерьеров. Тёмная премиальная дизайн-система,
адаптивная вёрстка, без фреймворков — чистый HTML, CSS и JavaScript.

## Структура

```
index.html        — единственная страница со всеми секциями
css/style.css      — стили и дизайн-система
js/main.js         — интерактив (скролл, фильтры портфолио, форма, курсор)
fonts/             — TT Norms Pro (основной текст)
images/            — изображения (hero, портфолио)
.claude/launch.json — конфиг локального запуска через http-server
```

## Локальный запуск

Из-за относительных путей и шрифтов сайт нужно открывать через локальный
сервер, а не как `file://`:

```bash
# Python
python3 -m http.server 8777
# или Node
npx --yes http-server . -p 8777 -c-1
```

Затем откройте <http://localhost:8777>.

## Как заменить контент

- **Изображения портфолио** — положите свои рендеры в `images/` и подставьте
  их в карточки в `index.html` (сейчас часть карточек — плейсхолдеры с подписями).
- **Шрифт заголовков Canela** — коммерческий (Commercial Type). Положите
  лицензионные файлы `Canela-*.woff2` в `fonts/`, и они подхватятся
  автоматически. Пока файлов нет, заголовки используют фолбэк Cormorant
  Garamond из Google Fonts.
- **Цены и услуги** — правятся прямо в секциях `#pricing` и `#services`.
- **Контакты и соцсети** — ссылки в подвале `index.html`.
